# Security Policy

## Supported Versions

Security updates and critical fixes are applied to the latest release on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Yes                |
| < 0.1.0 | No                 |

## Reporting a Vulnerability

If you discover a security vulnerability or sensitive information handling flaw within this project:

1. Please do not open a public issue.
2. Report the vulnerability privately via GitHub Security Advisories:
   Navigate to the **Security** tab of this repository and select **Report a vulnerability**.
3. Alternatively, contact the maintainer directly via the email listed on their GitHub profile.

Please include:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept to reproduce the issue.
- Your suggested mitigation, if known.

We will review the submission, investigate promptly, and release a fix as soon as possible.
